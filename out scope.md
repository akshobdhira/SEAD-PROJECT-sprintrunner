## 8. Scope Definition – Out-of-Scope

The following features and functionalities are considered **out-of-scope** for the Sprint Retrospective Analyzer project. These items are excluded to maintain focus, manage complexity, and align with the academic and prototype-level nature of the project.

### Out-of-Scope Features

- Integration with third-party Agile tools such as Jira, Azure DevOps, or Trello
- Real-time sentiment analysis using advanced machine learning or deep learning models
- Automated decision-making or recommendation engines for sprint planning
- Mobile application development for Android or iOS platforms
- Enterprise-scale user management and multi-organization support
- Real-time collaboration features such as live editing or chat during retrospectives
- Performance optimization for large-scale, production-level workloads
- Handling of sensitive enterprise or confidential organizational data
- Compliance with industry-specific regulations or standards
- Continuous deployment and production monitoring pipelines

Defining these out-of-scope elements ensures that the project remains achievable within the given timeframe while delivering meaningful and well-structured retrospective analysis capabilities.
